# Multi-Agent Career Intelligence Platform

## Overview

A Machine Learning based career assistance platform that helps students analyze resumes, identify skill gaps, predict placement opportunities, prepare for interviews, and generate personalized learning roadmaps.

## Features

### Resume Analyzer

* Extracts skills, CGPA, projects, and certifications from resumes.
* Generates a resume score based on candidate profile strength.

### Skill Gap Detector

* Compares existing skills with target role requirements.
* Identifies missing skills and calculates readiness percentage.

### Placement Predictor

* Uses a Decision Tree Classifier to predict placement likelihood.
* Implements supervised machine learning techniques.

### Interview Question Generator

* Generates skill-based interview questions.
* Supports preparation for technical interviews.

### Learning Roadmap Generator

* Creates personalized learning plans based on missing skills.
* Recommends a structured improvement path.

## Technologies Used

* Python
* Scikit-Learn
* Machine Learning
* Decision Tree Classifier
* Google Colab

Dataset → Feature Extraction → Train-Test Split → Model Training → Prediction → Evaluation
